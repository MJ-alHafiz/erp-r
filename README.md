# Respack ERP - Web ERP for Plastic Packaging

Live Demo: Enable GitHub Pages on index.html

Features:
- Quotation Calculator (Respack Formula: W x L x Micron x Density)
- Sales Order Management
- Production Floor (Extrusion Line tracking)
- Inventory (LDPE, LLDPE, HDPE, Masterbatch)
- QC Roll Barcode System
- Dashboard with OEE, Scrap %

How to use:
1. Open Quotation -> enter spec -> Create SO
2. Sales -> send to Production
3. Production -> enter produced KG
4. QC -> scan rolls

Next step: Connect to Supabase / Firebase for multi-user.
